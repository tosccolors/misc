Tier validation: Reevaluate reviews
===================================

For complex validation flows, it is desirable to leave existing reviews untouched when changes in the objects a tier definition uses neccessiate recomputation of reviews.

With this addon, instead of restarting a validation and then re-requesting validation on a record, you can use the action "Reevaluate pending validations" on tier definitions to update all pending reviews from the current tier definition.
