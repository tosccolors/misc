Reconcile to suspense account
=============================

This module adds a 'Mark fully paid' button below the original amount in the reconciliation screen when an invoice was selected whose amount doesn't match the transaction's amount. Clicking it will set the invoice as fully paid, but will assign the balancing amount to the bank suspense account, in opposition to the 'Fully paid' button on the manual reconciliation tab, which balances with the invoice line's account.
